# About this Remix {-}

This is a draft of a remixed version of Dan Korman's [Learning from Arguments: An
Introduction to Philosophy](https://philarchive.org/rec/KORLFA). 

Immediate goals of this remix are:

- [ ] Reformat the book as an accessible multi-format webpage published using
  Quarto.
  - [ ] Remove anything that assumes that these are the only chapters.
  - [ ] Wrap all arguments in `:::{#ID .argument}` divs
  - [ ] Replace all cross-references to chapters, sections, tables, arguments,
    theses, and examples with automatically generated cross-references
  - [ ] Figure out how to render Korman's preferred standard form in all
    formats.
  - [ ] Figure out how to render Korman's examples the same in all formats.
  - [ ] Replace Appendix C with automatically generated lists.
  - [ ] Replace extra readings/sources with properly generated citations.
- [ ] Modify the existing chapters in small ways to suit my own teaching.
- [ ] Supplement each chapter with additional materials for use in the
  classroom (handouts/slides/quizzes/...)
- [ ] Add additional chapters on additional topics.
